# Atelier

Krishna Raju S's portfolio as a maker's workshop for factory software. A short loader opens the workshop, then his name is set in heavy wide type on a chalk ground inside an ink bezel. The nine production apps play on an amber bench monitor: turn the channel dial, or pick an app from the list under it. After that come the side projects as hanging tags, the AI work on a dark panel, the record oldest first, honours with photos, a tool wall, and contact. On a desktop the pointer leaves water ripples on the page and bends any photo it passes over. Phones get the same content without the custom cursor, and visitors who ask for reduced motion get it without smooth scroll, ripples or reveals.

Inspired by https://madebyhart.com/, mainly its channel-dial TV, rounded page corners and pill buttons. The layout ideas are borrowed; the code, type and content are Krishna's own.

## Run it

```sh
npm install
npm run dev
```

All facts live in `src/content.js`. Sibling concepts live on the other `portfolio/*` branches.
