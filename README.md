# Sunrise

Krishna Raju S's portfolio as a type specimen at dawn. A grainy sun rises to fill the sky as you scroll, then fades to dusk. Inside: a catalogue of the nine production apps with weight and softness sliders that retune the variable serif, a line tester you can type into, the five internships with photos that follow your pointer, and a setting sun to say thanks.

Inspired by https://casadisolare.com/. The layout ideas are borrowed; the code, type and content are Krishna's own.

## Run it

```sh
npm install
npm run dev
```

All facts live in `src/content.js`. Sibling concepts live on the other `portfolio/*` branches.
