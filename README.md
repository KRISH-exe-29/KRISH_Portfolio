# Krishna Raju S | Issue 01

**Live site: https://krish-exe-29.github.io/KRISH_Portfolio/**

The portfolio of Krishna Raju S, an electrical engineer who ships software, built as a one-engineer magazine.

- **Cover:** the name is a variable font whose weight follows your pointer.
- **Nine apps:** a horizontal spread of the apps running in production at Indo Tech Transformers.
- **Feature:** five internships, with photos pinned beside the text.
- **Centrefold:** growing an AI agent in twelve versions, plus a retrieval assistant for work instructions.
- **Classifieds:** the patent, awards, skills and certifications.
- **Back cover:** email, resume, LinkedIn and GitHub.

The soundtrack is off until you press "Play soundtrack". Phones, and visitors who ask for reduced motion, get a plain vertical magazine.

## Run it locally

```sh
npm install
npm run dev
```

All facts live in `src/content.js`. Built with Vite, React and GSAP.

## Deploying

Every push or merge to `main` rebuilds and publishes the site through GitHub Actions (`.github/workflows/deploy.yml`). It is usually live within a minute or two.

## Other concepts

Two alternative designs with the same content live on their own branches:

- `portfolio/grid-run`: a playable night drive, with a gate for every stage of the career.
- `portfolio/energize`: a single-line diagram that powers up as you scroll.
