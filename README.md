# Workbench

Krishna Raju S's portfolio as a toy workbench. A small CSS-only 3D desk leans toward your pointer, then a hologram of Krishna is scanned into a photo as you scroll, with callouts and a counter. After that: the five internships as a circuit, the nine production apps as cards, and a trophy shelf. Phones get the same content stacked; visitors who ask for reduced motion get it without the scan.

Inspired by https://david-hckh.com/. The layout ideas are borrowed; the code, type and content are Krishna's own.

## Run it

```sh
npm install
npm run dev
```

All facts live in `src/content.js`. Sibling concepts live on the other `portfolio/*` branches.
