# Krish Originals

Krishna Raju S's portfolio as a streaming series. An opening "K" ident, a "Who's watching?" picker (Recruiter, Engineer, Just curious) that reorders the rows, the nine factory apps as K Originals, the career as seasons, recognition as a Top 10 row, and a project modal. Esc closes the modal; arrow keys scroll a focused row. Reduced-motion visitors skip the ident.

One static file, no build: open `index.html`, or publish the folder with GitHub Pages. Facts sit at the top of the `<script>` and mirror `KRISH_Portfolio/src/content.js`.
