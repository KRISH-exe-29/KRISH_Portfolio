# Typeset

Krishna Raju S's portfolio set like a Swiss type specimen. One twelve-column grid, one sans in very large sizes, a mono for labels, and a single yellow. A counter sets the name in letter by letter, the nine production apps sit in a ruled index that fills with yellow under the pointer, the agent's twelve versions grow heavier as they go, and the pointer moves through the page like ink dropped in still water, refracting the photos as it passes.

Inspired by https://www.quangdinh.im/. The layout ideas are borrowed; the code, type and content are Krishna's own.

## Run it

```sh
npm install
npm run dev
```

All facts live in `src/content.js`. Sibling concepts live on the other `portfolio/*` branches.
