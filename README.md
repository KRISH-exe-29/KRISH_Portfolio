# Canvas

Krishna Raju S's portfolio as a designer's case-study wall. The work is the first thing on the page: nine production apps, side projects, AI pieces and field photos in one flat gallery, each tagged with a single letter and filterable by it, with a switch to an index list. No screenshots exist, so each app gets a typographic cover drawn from its own name and pitch. The loader counts the covers as it draws them, and the last one flies into its tile. Opening a tile carries its image into a case-study panel. A thin water surface follows the pointer, and media ripples and splits colour under it.

Numbers, about, the twelve-version agent, experience with photos, recognition, toolkit and contact follow below. Reduced-motion visitors get native scroll and no water or cursor; touch screens keep the native cursor; browsers without WebGL fall back to plain image hovers.

`npm install`, then `npm run dev`. Facts come from `src/content.js`, the same file on every concept branch.
