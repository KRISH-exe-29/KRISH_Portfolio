# Headline

Krishna Raju S's portfolio as a loud two-colour poster. The cover sets "Results over resumes" in heavy navy type beside a duotone portrait, and the rows slide apart as you scroll. Inside: the nine production apps as numbered episodes, a running band of one-liners, the numbers, five internships as seasons, and a contact page that fills the screen.

Inspired by https://www.jeanrottner.com/. The layout ideas are borrowed; the code, type and content are Krishna's own.

## Run it

```sh
npm install
npm run dev
```

All facts live in `src/content.js`. Sibling concepts live on the other `portfolio/*` branches.
