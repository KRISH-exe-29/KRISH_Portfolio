# Krishna's Notebook

Krishna Raju S's portfolio as a ruled notebook: lowercase, casual copy, photo pages you can drag around the desk, a "right now" list, numbered wins, projects, work and a toolbox. Keyboard-first: `g` then `p` / `w` / `a` / `r` / `c` / `h` jumps to a section, `d` toggles dark mode, `?` opens the cheat sheet, Esc closes it. On phones the pages stack.

One static file, no build: open `index.html`, or publish the folder with GitHub Pages. Facts sit at the top of the `<script>` and mirror `KRISH_Portfolio/src/content.js`.
