# Grid Run

Krishna Raju S's portfolio as a night drive. You steer a car down a highway at dusk, and every gate you pass is a stage of his career: five internships, an IIT Bombay ranking, a patent, nine production apps and his AI work. The street lights wake up as the car approaches, the way his patented street light does.

Not in the mood to drive? "Skip the drive, read the log" shows the same content as a normal page. Visitors who ask for reduced motion get the log first.

Live: https://krish-exe-29.github.io/KRISH_Portfolio/grid-run/

## Run it

```sh
npm install
npm run dev
```

`node src/game/track.check.js` checks the driving model. All facts live in `src/content.js`.

Two sibling concepts live on the `portfolio/energize` and `portfolio/issue-01` branches.
