# Energize

Krishna Raju S's portfolio drawn as a single-line diagram. A live busbar runs down the page; as you scroll, breakers close and each sheet of the drawing powers up: the source, a tap changer that steps through five internships, a distribution board of nine production apps, ladder logic for his AI agent, protection flags for the patent and awards, and the load.

Visitors who ask for reduced motion get the same drawing fully energised, with no pinning.

Live: https://krish-exe-29.github.io/KRISH_Portfolio/energize/

## Run it

```sh
npm install
npm run dev
```

All facts live in `src/content.js`. Two sibling concepts live on the `portfolio/grid-run` and `portfolio/issue-01` branches.
